1. ชุดทดสอบอัตโนมัติ

รันด้วย node tests/all.js — ทดสอบ logic การจำแนกและคำนวณล้วนๆ (ไม่พึ่ง browser) กด ▸ ดูรายชื่อเทสได้

check-structure.js
ตรวจว่า element id ที่โค้ดพึ่งพาอยู่ครบในหน้าเว็บ 1 test
  • ครบทั้ง 18 id ที่จำเป็น (grid, ปุ่ม, ช่อง input, container ของตาราง)
run-tests.js
พฤติกรรมหลักของทุกฟีเจอร์ที่เพิ่มมาตลอด 18 tests
  • normalizeWO / normalizeCategory (ตัดช่องว่าง, ไม่สนตัวพิมพ์เล็ก-ใหญ่)
  • parseMappingText ข้าม header และแถวว่าง
  • splitPasteBlock กระจายข้อมูลที่วางลงตาราง
  • parseDataRows รวมชั่วโมงรายวัน, ข้ามแถวอ่านไม่ได้
  • classifyRows ติดป้าย UNMAPPED และไม่เดาเป็น CAPEX
  • buildTable1 แปลง MH → Man-Day, sort ตาม WO No., เก็บ woNo แยกจาก label
  • table1ToRows แยก WO No. กับ WO Name เป็นคนละแถว
  • buildTable2 คำนวณ % และคืนค่า null เมื่อไม่มีชั่วโมงที่ chargeable
  • formatMH / formatPct ปัดเศษ 2 ตำแหน่ง
  • toCSV / toTSV escape เครื่องหมายพิเศษถูกต้องตาม RFC 4180
edge-cases.js
เคสขอบ — เลขติดลบ, ภาษาไทย, ข้อมูลซ้ำ, ช่องว่าง 30 tests
  • เลขติดลบ, comma คั่นหลักพัน, ข้อความปนตัวเลข ("8hrs")
  • แถวมีแค่ 5 คอลัมน์ (ไม่มีชั่วโมงเลย) → mh เป็น 0 ไม่ error
  • ชื่อคน/ทีม/งานเป็นภาษาไทยไม่พัง
  • WO No. ซ้ำกันในตาราง Mapping (ทั้งตัวพิมพ์เดียวกันและคนละ case)
  • ข้อมูลว่างเปล่าทั้งหมด → คืน structure ว่าง ไม่ throw
  • รวมชั่วโมงติดลบได้ (กรณีแก้ไขยอดย้อนหลัง)
  • neutralizeFormula กัน =, +, @ แต่ไม่แตะตัวเลขติดลบจริง
  • toCSV/toTSV ป้องกัน formula injection โดยไม่ทำเลข Man-Day ติดลบเพี้ยน
e2e.js
ข้อมูลตัวอย่างมาตรฐานไหลผ่าน pipeline เต็มรูปแบบ 5 tests
  • 7 แถว, 4 squad, 1 WO ที่ไม่รู้จัก — parse ผ่านครบ ไม่มีแถวถูกข้าม
  • คอลัมน์เรียงกลุ่ม CAPEX → OPEX → Non Charge → Unmapped ถูกต้อง
  • ยอดรวม Man-Day ต่อ squad และ % CAPEX/OPEX ตรงกับที่คำนวณมือ

2. บั๊กที่พบและแก้ไข

ทั้งหมดแก้และยืนยันซ้ำแล้วว่าใช้งานได้จริงผ่าน browser จริง ไม่ใช่แค่เดา

  1. 01อัปโหลดไฟล์ .xlsx เดิมซ้ำแล้วไม่มีอะไรเกิดขึ้นFixed
    ช่องเลือกไฟล์ไม่รีเซ็ตค่าหลังอ่านเสร็จ→เลือกไฟล์เดิมซ้ำ browser จึงไม่ยิง event ให้ ตอนนี้รีเซ็ตช่องหลังอ่านทุกครั้ง
  2. 02ไฟล์ .xlsx เสีย/ถูกเปิดใช้งานอยู่ → ล้มเหลวเงียบๆFixed
    ไม่มี error handler ตอนอ่านไฟล์ล้มเหลวระดับระบบ→เพิ่มข้อความแจ้งเตือนภาษาไทยเมื่ออ่านไฟล์ไม่สำเร็จ
  3. 03Download CSV เสี่ยงล้มเหลวบน FirefoxFixed
    ลบ URL ของไฟล์ทิ้งทันทีหลังกดดาวน์โหลด เป็น race condition ที่รู้จักกันดีใน Firefox→หน่วงการลบออกไป 1 วินาที
  4. 04เสี่ยง CSV formula injectionFixed
    ถ้าชื่อ Squad/WO ขึ้นต้นด้วย =, +, @ แล้วเปิดใน Excel อาจถูกตีความเป็นสูตร→เติม ' นำหน้าอัตโนมัติ เฉพาะข้อความ ไม่แตะตัวเลขติดลบจริง
  5. 05WO No. ซ้ำในตาราง Mapping ทับกันเงียบๆFixed
    ถ้าพิมพ์ WO เดิมสองแถวคนละ Category แถวหลังจะทับแถวแรกโดยไม่มีใครรู้→ขึ้นแบนเนอร์เตือนพร้อมชื่อ WO ที่ซ้ำ
  6. 06อัปโหลดไฟล์ที่ไม่ใช่ Excel จริง → ข้อความกำกวมFixed
    ได้ข้อความ "Loaded 0 rows" เหมือนไฟล์ Excel ที่ว่างจริง แยกไม่ออก→เช็ค magic byte ของไฟล์ zip (.xlsx คือไฟล์ zip) ก่อน แจ้งชัดเจนว่าไม่ใช่ไฟล์ Excel
